# GtagStuff-GameNative
THIS IS ONLY FOR QUEST 3 AND 3s, QUEST 2 WOULDN'T BE ABLE TO RUN IT!!

Manually set the gorilla tag config on gamenative by going into the game and pressing the gear icon button next to the green Launch button then find "edit container".

This is for only if you already have gorilla tag on steam and gamenative legacy xr from https://github.com/utkarshdalal/GameNative.
